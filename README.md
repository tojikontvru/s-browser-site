# S Браузер — сайт

Публичный репозиторий только для сайта и загрузки APK.
Исходный код приложения лежит в приватном репозитории `s-browser`.

- Сайт: https://tojikontvru.github.io/s-browser-site/
- Документы (политика и условия): https://tojikontvru.github.io/s-browser-legal/

После каждого релиза обновлять здесь: `index.html` (версия, дата, размер,
SHA-256) и файл `S-Browser-X.Y.apk`.
